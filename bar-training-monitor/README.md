# Мониторинг подготовки претендентов в адвокаты

Еженедельный обзор по всему миру: как готовят претендентов на статус адвоката —
учебные планы и программы, стоимость, сроки и даты, форматы, стажировки,
квалификационные экзамены, реформы допуска.

Зоны совпадают с зонами агентов мониторинга ИИ в юридической практике:
RU (Россия, ЕАЭС, Центральная Азия), NA (США, Канада), CL (общее право вне Северной
Америки), EU (континентальная Европа и наднациональный уровень), AS (Азия).

**Адрес для отчёта** передаётся в prompt запуска (в репозиторий адреса почты не записываются — см. `CLAUDE.md`).
**Периодичность:** еженедельно (пятница).

## Файлы

| Файл | Назначение |
|---|---|
| `INSTRUCTIONS.md` | инструкция агента-координатора: порядок запуска, сборки, отправки |
| `zones/_common.md` | общая часть промпта зональных агентов: предмет, правила, JSON-схема |
| `zones/RU.md`, `NA.md`, `CL.md`, `EU.md`, `AS.md` | юрисдикции, первоисточники, запросы на языках оригинала |
| `build_report.py` | сборка: слияние с базой, изменения цен и сроков, рубли по курсу ЦБ, HTML/CSV |
| `data/baseline.json` | база программ на дату последнего запуска (только открытые сведения) |
| `data/recheck.json` | что перепроверить в следующий запуск |
| `reports/ГГГГ-ММ-ДД.html` | архив отправленных отчётов |

## Prompt для запуска по расписанию

```
Выполни еженедельный мониторинг подготовки претендентов в адвокаты по инструкции
bar-training-monitor/INSTRUCTIONS.md. Дата запуска: <сегодня>. Отчёт отправь на
<адрес>. Обнови data/ и reports/, закоммить и запушь в рабочую ветку.
```

## Требования к окружению

- веб-поиск и загрузка страниц;
- коннектор Gmail с правом отправки;
- доступ к `www.cbr.ru` для курсов валют (без него отчёт выходит без рублёвых эквивалентов).
