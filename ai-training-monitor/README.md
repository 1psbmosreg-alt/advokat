# ai-training-monitor — мониторинг обучения адвокатов использованию ИИ

Ежедневный (пн–пт) агент: обходит реестр источников `watchlist.csv`, отбирает новое об обучении
и повышении квалификации адвокатов по ИИ, раскладывает по группам, странам и уровням программы
М0–М6 и отправляет письмо-таблицу. Модель читает страницы и оценивает события; арифметику,
дедупликацию и вёрстку выполняет `scripts/build_report.py`.

| Файл | Назначение |
|---|---|
| `CLAUDE.md` | постоянная инструкция агента |
| `TASK_PROMPT.txt` | шаблон текста плановой задачи (адрес подставляется только в задаче) |
| `watchlist.csv` | реестр: код, группа, страна, орган, тип, название, адрес, уровень A/B, статус, дата и способ проверки адреса |
| `scripts/build_report.py` | `plan` — страницы на сегодня и окно; `build` — проверка, дедупликация (60 дней), динамика 7/30 дней, HTML/MD, накопительная таблица |
| `scripts/send_report.py` | запасная отправка по SMTP (получатель — только из `MAIL_TO`) |

Данные запусков хранятся не здесь, а в `1psbmosreg-alt/claude`, ветка
`claude/ai-legal-news-agent-usa-dd5jaf`, каталог `reports/TRAINING/`:
`state/seen.json`, `state/events.csv`, `state/last_run.json`, `runs/ГГГГ-ММ-ДД.json`,
`ГГГГ-ММ-ДД.html|md|subject.txt`.

Столбец `url_check` реестра: `открыт ГГГГ-ММ-ДД` — страница открывалась при составлении;
`выдача WebSearch ГГГГ-ММ-ДД` — адрес взят из поисковой выдачи на домене органа, но страница
не открывалась (сетевая политика среды); такие адреса подтверждаются первым запуском в режиме
`страницы`.

Режим `только_поиск`: если в среде запуска не работает WebFetch, агент ищет только через
WebSearch по доменам реестра, ни одно событие не получает статус ПРОВЕРЕНО, тема письма
помечается «ОХВАТ НЕПОЛНЫЙ».

Проверка скрипта локально:

```
python3 scripts/build_report.py plan --watchlist watchlist.csv --data-dir /tmp/d
python3 scripts/build_report.py build run.json --watchlist watchlist.csv --data-dir /tmp/d --dry-run --out /tmp
```
