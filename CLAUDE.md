# advokat

Репозиторий открытый. НЕ записывать сюда данные доверителей, номера дел, ФИО, суммы,
адреса почты, идентификаторы файлов Google Диска — только общие инструкции.
Реестр дел хранится на Google Диске владельца; его ID передаётся в задании (prompt).

Ежедневный мониторинг судебных дел: см. `monitoring/INSTRUCTIONS.md`.
